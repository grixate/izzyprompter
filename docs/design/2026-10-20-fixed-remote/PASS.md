# Пульт — один неподвижный экран

20 октября 2026. Цель владельца: весь интерфейс пульта помещается на телефоне без скролла; текущий пассаж редактируется в drawer/overlay.

[Рабочий пульт](http://127.0.0.1:8780/2026-10-20-fixed-remote/live/index.html?skin=groove) · [Все выбранные14](http://127.0.0.1:8780/2026-10-20-fixed-remote/review.html)

## Реализация

`remote-viewport.css` задаёт ограниченную высотой viewport сетку. Свободная высота достаётся колесу, а не увеличивает страницу. На коротком телефоне навигация, Quick Edit и выбор скина делят нижний ряд; кнопки сохраняют45px. На особенно коротком портретном экране скорость стоит сбоку. В landscape колесо слева, время/скорость/навигация справа. Прокрутка запрещена и фактически не требуется: проверяется scrollHeight, положение каждого элемента и отсутствие пересечений, а не только overflow:hidden.

Корпуса, SVG, состояния и самостоятельные регуляторы выбранных14 сохранены. Исправлены высоты Arcade, clearance слота Cartridge над брендингом и расстояние от нижних меток ручки до её подсказки. Структурная верстка применяется также к историческим ID; выбранная коллекция остаётся14.

`RemoteDrawer` — общий native modal для рабочего Quick Edit и синтетического просмотра. Он вынесен порталом из корпуса, оставляет фон inert, удерживает Tab/Shift+Tab, возвращает фокус к кнопке. VisualViewport resize/scroll держит drawer над экранной клавиатурой. Header/footer закреплены; прокрутка допускается только внутри редактора/его текста. При очень низкой видимой области заголовок визуально скрывается, сохраняя доступное имя; textarea и Done остаются видны.

Серверная работа Quick Edit сохранена: актуальный пассаж определяется по reading checkpoint, воспроизведение останавливается, live sync/наблюдение/несохранённый черновик/конфликт не обходятся. В демо удалён inline editor. Новый standalone просмотр14 показывает настоящий размер неподвижного пульта вместо высокой лабораторной карточки.

У Direct-пульта кнопка pairing перенесена в существующий ряд инструментов. Нижняя внешняя панель больше не добавляет вторую страницу после подключённого пульта.

Повторная быстрая проверка скорости выявила ещё одну гонку: после ACK приходил reading checkpoint со старым transport. Теперь подтверждённая revision задаёт нижнюю границу синхронизации. Проверка с удержанными WebSocket transport broadcasts и живыми reading checkpoints воспроизводит этот порядок; последнее значение сохраняется. Протокол не менялся.

## Доказательства

- 90 client unit tests и production build прошли. Diff check прошёл.
- 24 browser cases имеют успешные последние результаты в Chromium/Firefox/WebKit. Один чистый запуск24 прошёл; после финального изменения Cartridge и проверки короткой клавиатуры затронутые6 layout/drawer cases прошли ещё раз. `checks.json` сохраняет также исходные неуспешные проходы.
- Геометрия каждого из26 существующих ID проверена на8 размерах:320×480,320×568,360×640,390×660,390×844,568×320,844×390,768×1024 —624 сочетания. Это совместимость исторического каталога, а не расширение отбора14.
- Во всех этих состояниях scrollHeight не превышает clientHeight, интерактивные элементы внутри viewport, touch targets не меньше44px, колесо не меньше128px; нет пересечений readout/wheel/speed. Slot Cartridge имеет отдельный зазор от header.
- На реальном синтетическом парном сеансе drawer открывает текущий пассаж, текст появляется на display до Done, фон не меняет размеры, фокус остаётся в modal. Высоты доступной области250/400px, rotation и возврат на390×844 проверены. Done и textarea видны одновременно; закрытие и Escape возвращают управление пульту.
- Все4 существующих Quick Edit regression scenarios прошли в3 движках: два display + observer, live sync до Done, восстановление offline draft, конфликт с другим телефоном и недоступное локальное хранилище. Локаторы редактора уточнены по CURRENT PARAGRAPH, поскольку точное число скорости тоже является textbox.
- Матрица точности всех14 прошла в3 движках: жесты скорости, точный ввод, native keyboard, номинальное время, Play/Pause, reduced motion и фактический контраст.
- Собранный standalone просмотр14 отдельно прошёл3 движка на5 размерах (210 состояний), включая каждый drawer с доступной высотой250px и выбор скина. Нет ошибок страницы и session/account/API запросов (`preview-checks.json`). Снимки всех14 при320×568 просмотрены визуально.

Это браузерная эмуляция, не проверка физических iPhone/iPad/Android или реальной IME. Native Direct LAN gate пропущен существующим opt-in условием: этот Mac ранее выдавал недостижимый VPN ICE candidate. Он не объявляется пройденным. Изменение Direct UI использует тот же RemoteSurface; фактическая LAN-проверка остаётся ограничением runbook. CI не объявляется пройденным до его реального результата.

Предыдущие v3/v4/v5/collection сборки сохранены. Новый просмотр изолирован и работает со статическим сервером docs/design на8780. Production/staging, grants и default не менялись. Слияния и публикации нет.

Воспроизведение: `node docs/design/2026-10-20-fixed-remote/build-review.mjs`; затем `node docs/design/2026-10-20-fixed-remote/verify-review.mjs` при работающем сервере8780. Основная парная проверка: `npx playwright test test/e2e/remote-viewport.spec.ts test/e2e/quick-edit.spec.ts test/e2e/time-speed-craft.spec.ts`.
